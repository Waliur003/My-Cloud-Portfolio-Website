# Waliur R Sun — Cloud Engineering & Cloud Security Portfolio

A responsive personal portfolio focused on cloud infrastructure, automation, security engineering, and secure AI workloads.

**Live site:** [waliur-cloud-security.waliur003.chatgpt.site](https://waliur-cloud-security.waliur003.chatgpt.site)

## Portfolio highlights

- 10 cloud engineering projects covering AWS, Terraform, serverless systems, containers, Kubernetes, CI/CD, and observability
- 8 cloud security projects covering IAM, zero trust, encryption, threat detection, incident response, DevSecOps, and SIEM
- Detailed project cards and modals with architecture decisions, security controls, reliability, observability, lessons learned, technology stacks, and GitHub links
- Responsive dark cyberpunk interface with branded AWS and technology icons
- Skills, certifications, experience, education, social links, resume access, and an EmailJS-powered contact form

## Technology stack

- React 19 and TypeScript
- vinext, Vite, and Cloudflare tooling
- Tailwind CSS
- Lucide React and Simple Icons
- EmailJS Browser SDK

## Run locally

Node.js `22.13.0` or newer is required.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Useful commands

- `npm run dev` — start the local development server
- `npm run build` — create and verify a production build
- `npm test` — build and run the rendered HTML test
- `npm run lint` — run ESLint

## Repository structure

- `app/` — portfolio interface, content, components, and styling
- `public/` — static assets and resume
- `tests/` — rendered HTML verification
- `.openai/hosting.json` — Sites hosting configuration
